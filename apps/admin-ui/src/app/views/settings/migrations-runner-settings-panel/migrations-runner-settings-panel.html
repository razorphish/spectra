Migration runner

Controls how the admin API executes Drizzle migrate() when you use Run Pending, Run All, or Run migration on the Migrations tab.

When ON (typical for local dev): migrations use the same Drizzle connection as the rest of admin-ui-api — for Neon that is often the HTTP driver, which does not wrap a whole migration file in a single database transaction. A failed mid-file migration can leave partial changes; use branches, backups, and small migrations.

When OFF (default in NODE_ENV=production when no DB override): migrations run in a short-lived node-pg pool using DATABASE_DIRECT_URL if set, otherwise the active Spectra Postgres URL. Prefer a direct (non-pooler) URL for Neon, matching drizzle.config.ts / repo README guidance.
